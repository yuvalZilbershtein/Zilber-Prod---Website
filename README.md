# Zilber Prod — Website

Yuval Zilbershtein's music production / mix & mastering portfolio site.

Plain HTML/CSS/JS, no build step.

## Editing content
- Contact info, portfolio tracks/covers, and background images: [data.js](data.js)
- Text/layout: [index.html](index.html)
- Styling: [style.css](style.css)

## Running locally
Open `index.html` directly, or serve the folder:

```
python3 -m http.server 5173
```

## Deploying
Hosted via GitHub Pages from this repo (branch: `main`, folder: `/root`).
